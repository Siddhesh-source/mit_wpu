# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/Siddhesh-source/mit_wpu/security/advisories/new).

Include the affected area, steps to reproduce and the impact. We aim to reply within 72 hours.

## Scope

In scope: the API (`apps/api`), web app (`apps/web`), shared signing and verification code (`packages/shared`) and the `DocumentRegistry` contract (`contracts`).
